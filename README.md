# 🏥 Hospital Management System

A Console-Based Hospital Management System developed, by using Core Java Concept.

## 📌 Features
- Add Patient
- View Patients
- Update Patient
- Delete Patient
- Search Patient
- Add Doctor
- View Doctors
- Book Appointment
- View Appointments
- Admin Login System
- File Handling (Data Persistence)
- Exit

## 🛠 Technologies Used
- Core Java
- OOP Concepts
- File Handling
- Collections Framework
- Git & GitHub

## ▶ How to Run
1. Compile: `javac Main.java`
2. Run: `java Main`
